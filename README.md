# Tango Spectacle

Project Goal: Create a premium, high-end, and immersive multi-page website for a world-class Tango Company, inspired by the theatrical and dynamic aesthetic of Cirque du Soleil.

Visual Identity & Branding:

•⁠  ⁠Aesthetic: Theatrical, avant-garde, and dramatic. Use a dark theme (deep blacks/charcoals) with vibrant red accents for the logo and primary call-to-actions.

•⁠  ⁠Typography: Use a sophisticated, custom-feel serif font for headings (reminiscent of high-end performing arts) and a clean, legible sans-serif for body text.

•⁠  ⁠Media: The hero section must feature a background video loop (muted) that captures the intensity of Tango. Integrate the red company logo prominently.

Architecture & Navigation (Tabs):

Implement a dynamic navigation bar with the following sections:

1.⁠ ⁠Home: An immersive "landing" experience focusing on the company’s current energy.

2.⁠ ⁠The Show: A dedicated space for the current production (Show Title). This should feel like a sub-brand within the company.

3.⁠ ⁠The Company: Focusing on the history, mission, and global reach of the troupe.

4.⁠ ⁠Artists: Individual bio cards for the performers. Each card should feature an image and a poetic, "Cirque-style" biography highlighting their discipline.

5.⁠ ⁠Gallery: A masonry-style grid for the provided images, using lightboxes for full-screen viewing.

6.⁠ ⁠Tour/Tickets: A clean, functional schedule of upcoming performances.

Technical Requirements:

•⁠  ⁠Interactivity: Use Framer Motion for smooth scroll reveals, parallax backgrounds, and elegant page transitions to ensure the site feels "alive" and artistic.

•⁠  ⁠Components:

•⁠  ⁠A "Hero" component with video integration.

•⁠  ⁠"Artist Profile" components with hover effects that reveal details.

•⁠  ⁠A "Sticky" navigation bar that changes transparency on scroll.

•⁠  ⁠Layout: Use a modern, responsive grid. The distinction between "The Company" and "The Show" must be clear; the website represents the entire entity, with the show being the current highlight.

•⁠  ⁠Language: All copy and UI elements must be in English.

Image Placement Instructions:

•⁠  ⁠Incorporate the user-provided images into the Gallery and the Artist bio sections.

•⁠  ⁠Place the red logo in the header and the footer.
